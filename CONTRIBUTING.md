# 🤝 Contributing to BhashaBridge

Welcome to the **BhashaBridge** project!  
We're excited to have you here and appreciate your interest in making AI truly inclusive for Bharat. Whether you're a developer, researcher, teacher, designer, or just someone who cares about language equality — there's a place for you here. 



##  What Is BhashaBridge?

**BhashaBridge** is a rural-first, offline-capable web app that enables users to:
- Speak in their native language
- Get real-time translations (voice + text)
- And most importantly: contribute to an **open multilingual speech corpus**

By simply using the app, users help train future Indian language models. Our mission is to **amplify rural voices** and **build datasets that reflect India's linguistic diversity**.



##  Types of Contributions

You can contribute in many ways:

###  Code Contributions
- Fix bugs
- Add new features (e.g., language support, UI improvements)
- Improve performance or offline capability
- Integrate new models (STT, TTS, MT)

###  Data Contributions
- Submit sample phrases or folk stories
- Contribute audio clips in underrepresented dialects
- Help tag existing voice/text data with metadata (language, emotion, region, etc.)

###  Localization
- Translate app UI to other Indian languages
- Help design intuitive user flows for rural users

###  Design & UX
- Improve interface accessibility
- Design badges or gamification visuals
- Help with visual storytelling (demo video, posters)

### Documentation
- Write or improve technical docs
- Create guides for contributors and new users
- Maintain FAQs
