# BhashaBridge Project Roadmap

Welcome to the **BhashaBridge** roadmap!  
This document outlines our 4-week journey to build a voice-based AI tool designed for rural India, enabling speech recognition in regional languages.  
Together, we’re building an inclusive, open-source movement — one voice at a time! 🎙️🌍


## Week 1: Groundwork & Kickoff — “Laying the First Brick”

### Goals:
- [x] Finalize the project idea 
- [x] Set up Git repository & project boards
- [x] Define folder structure and base files (`README.md`, `LICENSE.md`, etc.)
- [x] Assign team roles (Backend, Frontend, Dataset Curation, PM)
- [x] Research open-source tools (Wav2Vec2, HuggingFace Datasets)
- [x] Draft UI wireframes (Figma or pen-paper)

---

## Week 2: Voice Upload System — “Collecting Voices of Bharat”

### Goals:
- [x] Build voice collection interface (HTML + Tailwind)
- [x] Enable audio upload (WAV, MP3)
- [x] Collect speaker metadata (language, age, gender, region)
- [x] Create SQLite schema for voice + metadata storage
- [x] Enable manual preview of uploaded voice samples
- [ ] Validate data format before submission
- [ ] Begin collecting 10+ voice samples for testing



## Week 3: AI Preparation & Community Growth — “Training the Brain”

### Goals:
- [ ] Clean and preprocess uploaded voice data
- [ ] Create scripts to convert WAV → JSON/CSV (for training)
- [ ] Prepare dataset for Hugging Face 
- [ ] Integrate basic Wav2Vec2 ASR model locally
- [ ] Begin model fine-tuning experiments (optional if time permits)
- [ ] Add contributors.md and shoutouts
- [ ] Promote voice donation via social media



## Week 4: Dashboard, Wrap-Up & Public Launch — “Speaking to the World”

### Goals:
- [ ] Build basic analytics dashboard to track voices collected
- [ ] Deploy static UI on GitHub Pages / Netlify
- [ ] Write complete documentation (`README`, `CONTRIBUTING`, `REPORT`)
- [ ] Upload dataset to Hugging Face
- [ ] Publish demo video & final pitch
- [ ] Submit to hackathons / open-source showcases



## Stretch Goals (If Time Permits)
- [ ] Automatic speech validation (silence, noise, length checks)
- [ ] Multilingual model support (Kannada, Telugu, Hindi, etc.)
- [ ] Real-time transcription display
- [ ] Leaderboard for top contributors
- [ ] QR code for instant mobile voice uploads


## Long-Term Vision

BhashaBridge is not a 4-week sprint — it’s a movement.  
We dream of building a **HuggingFace of Indian Voices**, where anyone can contribute and train voice AI in their own language.  
From government apps to classrooms — let’s empower India, one voice at a time. 🇮🇳
