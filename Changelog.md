# Changelog — BhashaBridge

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),  
and this project adheres to [Semantic Versioning](https://semver.org/).



## [1.0.0] - 2025-07-24  
### Initial Launch — "Voices of Bharat"

First official release of **BhashaBridge**  
Empowering rural India with voice-driven AI tools in regional languages.

#### Added
- `README.md`, `LICENSE.md`, `CONTRIBUTING.md`, and `REPORT.md`
- Basic contributor guidelines and issue templates
- Initial project structure for:
  - Voice collection UI (HTML + Tailwind)
  - Backend API setup (Flask)
  - Dataset format specification
- Voice upload feature (manual, WAV/MP3)
- SQLite schema for storing speaker metadata
- Hugging Face dataset upload plan
- Basic dashboard UI prototype
- Community links and badges



## [0.1.0] - 2025-07-18  
### Project Kickoff — "Hello World"

#### Added
- Project idea finalized: Voice-based AI for rural India
- Core team formed and responsibilities assigned
- GitHub repository initialized
- High-level roadmap and goals outlined
- First draft of `ROADMAP.md`
